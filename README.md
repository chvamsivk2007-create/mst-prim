# MST using Prim’s Algorithm 🌐

C++ program to construct a Minimum Spanning Tree (MST) using **Prim’s Algorithm**.

---

## 📖 Description
- Starts from a vertex
- Greedily selects minimum weight edge connecting to new vertex
- Expands MST until all vertices are included
- Time Complexity: O(V^2) (or O(E log V) with priority queue)

---

## ▶️ Compilation & Run
```bash
g++ prim.cpp -o prim
./prim
